# PathPilot AI 🚀

### Personalized Learning Roadmap Generator

> **Your Skills. Your Goal. Your Personalized Path.**

PathPilot AI is an intelligent web application that helps students create a personalized, step-by-step learning roadmap based on their **current skills, target career role, available study time, and learning preferences**.

Instead of wondering *"What should I learn next?"*, students can use PathPilot AI to understand their skill gaps and follow a structured path toward their target role.

---

## 🎯 Problem

Many students know the career role they want, such as:

* Data Analyst
* Web Developer
* AI/ML Engineer
* Full Stack Developer
* Cybersecurity Engineer

But they often don't know:

* What skills they already have
* What skills they are missing
* What to learn first
* Which resources to use
* How long each stage may take
* When they are ready to build real projects

PathPilot AI solves this problem by generating a personalized learning roadmap.

---

## 💡 Solution

The application collects information about the learner and generates a structured roadmap containing:

* Current skill analysis
* Target role
* Skill-gap identification
* Learning phases
* Recommended topics
* Learning resources
* Practical projects
* Milestones
* Estimated timeline
* Progress tracking

---

## ✨ Key Features

### 🧭 Personalized Onboarding

Users provide:

* Target career role
* Current skills
* Experience level
* Available study time
* Learning preferences
* Target timeline

### 🧠 Skill Gap Analysis

The system compares the user's current abilities with the skills required for their target role.

### 🗺️ Personalized Roadmap

Generates a structured learning journey divided into clear phases and milestones.

### 📚 Learning Resources

Provides suggested resources and topics for each stage of the roadmap.

### 🛠️ Project-Based Learning

Recommends practical projects so users can convert theoretical knowledge into real-world experience.

### 📊 Progress Tracking

Users can monitor completed milestones and overall learning progress.

### 🤖 AI Assistance

AI helps personalize the roadmap according to the learner's goals, existing skills, and available time.

### 📱 Responsive Design

Designed to work across desktop, tablet, and mobile devices.

## 🧩 Example

### User Input

**Target Role:** Data Analyst

**Current Skills:**

* Basic Python
* Excel
* Basic SQL

**Available Time:** 2 hours/day

### Generated Roadmap

```text
Phase 1 → Advanced Excel
Phase 2 → SQL
Phase 3 → Python for Data Analysis
Phase 4 → Statistics
Phase 5 → Data Visualization
Phase 6 → Real-world Projects
Phase 7 → Portfolio & Interview Preparation
```

The roadmap is organized according to the user's current level instead of giving the same learning path to everyone.
